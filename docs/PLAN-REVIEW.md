# Initial plan review

## What was retained

- ESP-IDF + native TinyUSB HID is the appropriate base.
- QMI8658C accel+gyro should be fused rather than using gyro integration alone.
- Tilt should control relative velocity rather than absolute position.
- GPIO1–3 / GPIO5–7 grouping is appropriate for the no-solder experiment.
- GPIO4 should remain non-clicking.
- LEDs should stay out of initial scope.
- startup calibration, hysteresis, debounce and a runtime re-centre are important.

## Gaps found

### Too much hardware coupling

The initial phase list could have led to estimator and touch logic being implemented directly inside ESP-IDF callbacks, making CI weak. The revised architecture requires pure host-testable logic.

### Framework/API drift was not bounded

The project now requires TM-001 to choose and pin an exact stable ESP-IDF release after verifying both the current touch driver and `esp_tinyusb`.

### Physical acceptance was mixed with compilation success

USB enumeration and touch ergonomics cannot be proven by GitHub Actions. The revised plan explicitly separates CI evidence from physical evidence.

### Touch grouping needed a clearer electrical rule

GPIO1–3 and GPIO5–7 are independent electrodes. They are fused only in software. This preserves per-channel calibration and avoids any accidental implication that pins should be wired together.

### QMI address assumptions were unnecessary

The driver will verify `WHO_AM_I=0x05` and can probe 0x6A/0x6B rather than embedding a fragile board assumption.

### Click-induced cursor motion deserved first-class treatment

A hand-held tilt pointer is uniquely susceptible to motion generated by the user's clicking action. This is now a measured TM-008 acceptance item with optional, narrowly scoped mitigation in TM-007.

### GPIO4 reference use was too speculative

GPIO4 stays a non-clicking separator/diagnostic channel. Common-mode subtraction will be adopted only if captured data shows it improves reliability.

## Result

The revised programme is split into parallel USB, IMU and touch tracks after a common CI foundation, followed by integration, hardening, physical tuning and release consolidation. This should allow rapid progress without sacrificing evidence quality.
